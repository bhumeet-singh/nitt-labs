# Nitt Labs | ਨਿੱਤ

**Practice. Learn. Connect.**

Data science and machine learning research for Gurbani literacy,
adaptive learning, and Sikh educational technology.

## About

Nitt Labs is the research and development initiative behind Nitt,
a digital platform designed to make Gurbani, Gurmukhi education,
and daily Sikh practice more accessible to the global Sikh community.

The project combines data science, natural language processing,
machine learning, and software engineering to develop accessible
and personalized educational tools.

## Research Objectives

### 1. Computational Gurbani Analysis

- Analyze Gurbani vocabulary and character frequencies.
- Explore linguistic patterns and vocabulary overlap.
- Evaluate vocabulary coverage across different Banis.
- Develop a corpus-informed Gurmukhi learning curriculum.

### 2. Adaptive Learning

- Explore publicly available language-learning datasets.
- Develop predictive models for vocabulary recall.
- Compare statistical and machine learning approaches.
- Design an experimental personalized review system.

### 3. Intelligent Gurbani Discovery (Future Work)

- Explore natural language processing techniques.
- Evaluate information retrieval and search algorithms.
- Develop source-linked Gurbani discovery tools.
